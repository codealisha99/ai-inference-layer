Run it your way.

Start the Python reference implementation locally with Python 3.12+ and uv.

Or use this site’s API from your own client. The interactive docs cover registration, batch inference, streaming, and history.

Full setup guide ↗
  1. 1. Get the source
    git clone https://github.com/codealisha99/ai-inference-layer.git
cd ai-inference-layer/ai-inference-server-py
  2. 2. Install and start
    uv sync --extra dev
uv run python -m src.server
  3. 3. Register a model
    curl -X POST http://localhost:3000/models \
  -H 'content-type: application/json' \
  -d '{"name":"demo","type":"text-classification"}'
