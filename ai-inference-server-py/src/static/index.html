A small model registry and inference API.

Register a model, send it text, read back a result. Deterministic engines, bounded memory and one response envelope.

Try it

Engine
POST /models/{id}/inferidle 
Run an inference to see the response.

Engines

text-generation
Returns generated text for any input, optionally truncated with maxChars.
text-classification
A tiny sentiment lexicon with negation handling. Returns a label and a score.
embedding
A unit-length vector from a stable hash of the input. Up to 1,024 dimensions.

Quickstart

Needs Python 3.12 and uv.

  1. uv sync --extra dev
  2. uv run python -m src.server
  3. curl -X POST localhost:3000/models -H 'content-type: application/json' -d '{"name":"demo","type":"text-classification"}'
