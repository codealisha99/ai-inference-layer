# Ownership and attribution

AI Inference Layer is the repository and API project. Inference is its web
workbench. Product names and branding are separate from the maintainer's identity.

Package author metadata identifies the primary author. CODEOWNERS identifies the
primary review owner. Neither claims that every historical line was written by
one person. Git history remains the record of actual commit authors and contributions.

## Historical and third-party attribution

Preserve existing human and tooling commit identities, timestamps, and contributor
records. Do not rewrite history or map unrelated authors to the primary maintainer
to change contributor statistics. Future commits should use the genuine commit
author's identity and an email associated with that person's GitHub account.

Keep dependency, adapted-code, font, and other third-party copyright and license
notices. These identify the creators of those resources, not additional project
maintainers. IBM Plex font notices remain in
[`src/static/fonts`](./ai-inference-server-py/src/static/fonts/).

## License status

No project-wide license is currently specified. The font licenses apply to those
font assets; they do not license the rest of the project. A project license must
be selected by the maintainer with appropriate rights to the existing code.
